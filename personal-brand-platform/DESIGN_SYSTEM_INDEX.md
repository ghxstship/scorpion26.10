## 🎨 Quick Reference

### Color System
- **Greyscale:** 90% of UI (black to light grey)
- **Deep Red:** 5% of UI (#B50000 - CTAs, alerts)
- **Gold:** 5% of UI (#D4AF37 - success, focus)

### Typography
- **Display:** Bebas Neue (headings)
- **Body:** Inter (text)
- **Style:** UPPERCASE, bold, wide spacing

### Key Principles
1. **90/5/5 Rule** - Color distribution
2. **Token-First** - Zero hardcoded values
3. **WCAG AAA** - 7:1 contrast minimum
4. **Bold Typography** - Uppercase, heavy weights
5. **Dark Default** - Black backgrounds
